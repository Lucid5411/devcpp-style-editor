# Dev-C++ 风格代码编辑器

一个用 C# WinForms 实现的 Windows 桌面代码编辑器，支持多标签编辑、括号自动补全，
并可直接调用 `g++` 编译、运行当前源文件。

> 说明：本项目是一个**代码编辑器**，不包含编译器的实现——编译与运行通过调用系统中的
> `g++` 完成。项目参考了 Dev-C++ 的操作方式。

| 项目 | 说明 |
| --- | --- |
| 语言 | C# |
| 框架 | .NET Framework 4.7.2 |
| UI | Windows Forms |
| 开发环境 | Visual Studio 2022 |
| 依赖 | 系统中需安装 g++（MinGW / TDM-GCC），并加入 PATH |

## 功能

### 编辑

- 多标签页编辑，可同时打开多个文件
- 新建、打开、保存文件；标题栏用 `[*]` 标记未保存改动
- 状态栏实时显示总行数
- 支持 Tab 缩进、右键菜单

### 括号处理

- 输入 `{` 时自动补全 `}`
- 在 `{}` 之间再输入 `}` 时自动跳过，不产生重复括号
- 基于**栈**解析全书括号的配对关系与嵌套深度（`NowPage_BracketMakePair()`）

### 编译与运行

- 调用 `g++` 编译当前文件，编译错误显示在内置输出面板
- 运行时先定位 `main` 函数体的结束位置，在其前插入暂停语句后再编译执行，
  避免控制台程序执行完窗口立即关闭、看不到输出

## 运行方式

1. 用 Visual Studio 打开 `Dev-C++.sln`
2. 确保已安装 g++ 并可在命令行直接调用：

   ```bash
   g++ --version
   ```

   如未安装，可安装 MinGW-w64 或 TDM-GCC，并把 `bin` 目录加入系统 PATH。
3. 生成并运行项目（F5）

## 实现说明

- **括号配对**：使用 `Stack<int>` 遍历文本，遇到 `{` 压栈并记录位置，遇到 `}` 弹出栈顶完成配对；
  栈为空时遇到的 `}` 视为多余右括号，遍历结束后栈非空则说明存在未闭合的左括号。
  同时记录每个括号的嵌套深度，用于判断光标所在层级。
- **运行时注入暂停语句**：先定位 `main` 函数，再用括号计数法找到其函数体的结束位置，
  在该位置前插入 `getchar()` 后重新编译执行，执行完再还原源文件。
  这是为了让控制台程序的输出能被看到；更规范的做法是通过管道捕获子进程输出。
- **进程调用**：使用 `System.Diagnostics.Process` 启动 `g++` 与编译产物，
  设置 `UseShellExecute = false` 并重定向 `StandardError` 以捕获编译错误。

## 已知限制

- 无语法高亮、代码补全与调试功能
- 括号配对在每次按键时全量扫描当前文本，文件较大时会有性能问题
- 依赖外部 `g++`，未内置编译器
- 源文件路径与扩展名的解析较为简单，路径中含多个 `.` 时可能出错
